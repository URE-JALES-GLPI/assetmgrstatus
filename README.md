# Registro de Manutenção de Ativos

Plugin desenvolvido para auxiliar no **registro, acompanhamento e gerenciamento de manutenções de ativos**, centralizando o histórico de intervenções e facilitando o controle das atividades realizadas.

## 📋 Sobre

Este plugin tem como objetivo fornecer uma maneira simples e organizada de registrar todas as manutenções realizadas em ativos, mantendo um histórico completo para auditoria, acompanhamento e tomada de decisões.

Com ele é possível documentar desde pequenas correções até manutenções preventivas e corretivas, permitindo maior controle sobre o ciclo de vida dos equipamentos.

---

## ✨ Funcionalidades

* Registro de manutenções preventivas e corretivas.
* Histórico completo de intervenções.
* Registro de data e hora da manutenção.
* Identificação do técnico responsável.
* Descrição detalhada do serviço executado.
* Registro de peças substituídas.
* Observações adicionais.
* Controle do status da manutenção.
* Consulta rápida ao histórico de um ativo.
* Interface integrada ao GLPI.

---

## 🎯 Objetivos

* Centralizar todas as informações de manutenção.
* Melhorar a rastreabilidade dos ativos.
* Facilitar auditorias e inspeções.
* Auxiliar no planejamento de manutenções preventivas.
* Reduzir perda de informações em registros manuais.
* Organizar o histórico técnico dos equipamentos.

---

## 🖥️ Compatibilidade

* GLPI 11.x
* PHP 8.x

> A compatibilidade pode variar conforme a versão do GLPI utilizada.
